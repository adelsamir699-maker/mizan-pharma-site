# ميزان فارما

نظام إدارة صيدلية — نسخة مستقلة مبنية على ميزان.

- **افتح البرنامج:** https://adelsamir699-maker.github.io/mizan-pharma-site/
- **الدخول:** استخدم اسم المستخدم وكلمة السر التي يرسلها لك المالك.
- **التثبيت على الجهاز:** افتح الرابط في Chrome/Edge → اضغط «⬇️ تنزيل أيقونة البرنامج على الجهاز» أو من قائمة المتصفح «تثبيت التطبيق». يعمل على HTTPS مع Service Worker وPWA.
- **الشعار:** الثعبان + الكأس + الميزان (صورة المالك المعتمدة).

هذا المستودع للنشر الثابت فقط؛ الكود الخاص في مستودع `mizan-pharma` (خاص).
